
# Community Translations
Files listed here are available translations for BeamLR. These files translate both IMGUI and HTML UI apps text. Due to the vanilla translation files not translating some part names, slot names, tuning variables and other strings these will unfortunately also not be translated in BeamLR.
## Install Instructions
1. Download a translation zip file
2. Drop it in your mods folder

Tip: to download a translation file you have two options
1. Right click > Save link as... (or equivalent for your browser)
2. Left click > Click the "Download raw file" button (shown below)

![](https://i.imgur.com/VN4yqEt.png)
